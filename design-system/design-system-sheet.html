Prism system

Celebration spectrum reserved: poll won · all squared up · trip milestones

Allowed forms: a light sheen over glass, the 1.5 pt celebrate-button border, spectrum text on display/celebrate (use the text-* deep stops on light surfaces), and 3D confetti. Never as a UI fill, as a status colour, more than once per view, or while a task is in progress. Contrast: all text roles pass AA in both modes (on-accent 4.56; owed jade-600 4.9; owe rose-600 5.7; tertiary 5.3).
